Decisions:
- Busy sessions are not sent. They are added to the summary as `live` results, so it reads "N live skipped" as the server would report them. When every row is busy, no request is made.
- Dialog item name is `title · short id` (short id alone without a title), because ConfirmDialog keys rows by name and titles can repeat.
- The dialog is portalled to `.viz-root`, as the tip is, so it does not depend on the unpinned panel's visibility.
- Confirm label "Move to trash". The summary line stays until the next delete is opened. A failed request shows "could not move to trash (error N)", and refresh still runs.
- Delete picked acts on the shown pick, including the newest-session fallback when nothing is stored.
- Emptied drop: the key is removed, not []. Other tabs ignore the null storage event and reach the newest through their own pruned-to-empty fallback; tab 2 above confirms it.
