## Goal

In `readContext`, use the byte count `readSync` returns and decode only those bytes, so a short read (file truncated between `fstatSync` and `readSync`) never decodes the uninitialised tail of the `Buffer.allocUnsafe` buffer.

## Non-goals

- No other change to `readContext` or `lastUsage`: keep the window growth, the byte-level partial-line cut and the `start === 0` rule as they are.
- No switch back to `Buffer.alloc`; no retry loop on a short read.
- No new shell test case: a truncation race between fstat and read cannot be reproduced from the test script. The existing cases must pass unchanged.
- No README or version edits (T7 owns those).
