## Goal

A call row with `virtual` for a non-MCP tool shows its tool name as its label (rework item E). An MCP call row keeps its server label.

## Non-goals

- No change to `CATEGORY`, `toolColor` or the label markup at `:62-64`.

## Context

Source: T9 follow-up 4 in the T8 Comments.

- `web/src/components/EventRow.tsx:27`: `r.virtual ? String(r.tool).split('__')[1] : ...`. For a non-MCP tool (`Bash`) the split has no `[1]`, so the label is undefined. `Row.tool` is `string | null` (`shared/api.ts:46`).
- Change the virtual branch to `r.tool?.split('__')[1] ?? r.tool`. An MCP tool `mcp__srv__x` gives `srv`, as today. `Bash` gives `Bash`. A null tool gives null, so no label renders.
- The label logic does not read `OF` in `shared/api.ts`, so this ticket does not wait for T8.11.
