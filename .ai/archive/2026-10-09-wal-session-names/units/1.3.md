## Decisions
- Data source: no server change. `/session?id=<sess>&scope=agent:<id>` already returns that agent's
  `SessionSeries` (scripts/sessions.ts:161, scripts/transcripts.ts:273). `cumulative` has one entry per
  request (API call) in time order, so per-call usage = step of the cumulative column.
- Lazy: the charts component mounts only while the row is open; it fetches once on mount and
  refetches only when that agent's `requests` count in the scope-all view changes (live agents).
- Main row: no charts (duplicates the session panel). Subagent with 0 requests: no charts.
- Subagent cumulative chart has no turn markers (parent prompt turns mean nothing inside a subagent);
  title "Cumulative tokens". Bars: one per API call, title "Tokens per API call", x label "Call".
- Layout: `.ag-charts` grid in the expanded cell, side by side when wide, stacked when narrow;
  `width:0; min-width:100%` so the canvases never widen the table (uPlot follows the cell width via
  the existing ResizeObserver in charts/UPlot.tsx).

## Contracts
### a. perCall + chart props
- `web/src/lib/series.ts`: `export const perCall = (s: SessionSeries): Columns` →
  `[s.t.map((_, i) => i + 1), ...stack(LAYERS.map((k) => step(layer(s.cumulative, k))))]` where step(c)[i] = c[i] - c[i-1] (c[-1] = 0).
  Reuse `layer` (series.ts:7) and `stack` (series.ts:12). One-line comment: x is the call number from 1; each layer is that call's own usage.
- Test in series.test.ts on fixture `S` (series.test.ts:9): perCall(S) =
  [[1,2,3], [1,2,1], [11,12,11], [111,12,211], [111,17,213]] (input; +output; +cacheRead; +cacheWrite5m+1h).
  Plus empty series → [[], [], [], [], []].
- charts/TurnBars.tsx: add prop `by?: 'turn' | 'call'` (default 'turn'). 'call': cols = perCall(series), title "Tokens per API call",
  x series label 'Call'. 'turn': unchanged behaviour. useMemo deps include `by`.
- charts/TokensOverTime.tsx: add prop `markers?: boolean` (default true). false: `turns.current = []`, title "Cumulative tokens".
  true: unchanged. SessionsTab.tsx call sites stay as they are.

### b. hook, AgentCharts, wiring, CSS
- `web/src/useSession.ts`: `export function useAgentSeries(sess: string, agent: string, requests: number): { series: SessionSeries | null; error: string | null }`.
  fetch `'/session?' + new URLSearchParams({ id: sess, scope: `agent:${agent}` })`, take `.series` of the SessionView.
  Effect deps [sess, agent, requests]; reset series to null only when sess/agent change (keep the old series while a
  `requests` refetch is in flight); `alive` flag like useSessionViews; non-ok → error `error <status>`.
- `web/src/components/charts/AgentCharts.tsx` (new): `export function AgentCharts({ sess, agent, requests })` →
  error: `<div className="ag-note">Could not load this agent's charts ({error}).</div>`; null series: `<div className="ag-note">Loading…</div>`;
  else `<div className="ag-charts"><TokensOverTime series={series} agent markers={false} /><TurnBars series={series} agent by="call" /></div>`.
- `AgentRow.tsx`: optional prop `charts?: () => ReactNode`, rendered after the `<dl>` inside the same td when open.
- `SessionStats.tsx` ByAgent (SessionStats.tsx:97): pass `charts` only when `id !== 'main'` and `view.stats.agents[id]?.requests > 0`:
  `() => <AgentCharts sess={view.id} agent={id} requests={view.stats.agents[id]!.requests} />`.
- styles.css (after line 249):
  `.ag-x .ag-charts { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(360px, 100%), 1fr)); gap: 0 20px; margin-top: 12px; width: 0; min-width: 100%; }`

  Comment for width:0/min-width:100% (why: the canvas would otherwise set the table's min width, so it could never shrink).

### e. Review fixes
- Refetch key: streaming snapshots update a call's usage in place (scripts/transcripts.ts:162-168), so `requests` alone misses
  changes. Replace the hook's `requests: number` param with `stamp: string`; ByAgent passes
  `` `${r.requests}:${r.input + r.output + r.cacheRead + r.cacheWrite5m + r.cacheWrite1h}` `` for r = view.stats.agents[id]. AgentCharts prop `stamp: string`.
- useAgentSeries: AbortController per effect run, `fetch(url, { signal })`, abort in cleanup; an AbortError sets no error.
  On success clear error. Keep series on error (no reset except on sess/agent change, as now).
- AgentCharts: no series + error → error note; no series → Loading…; series → charts, plus the error note under them when error.
- README.md Sessions bullet: charts are fetched when the row expands and refetched on each new call or token change;
  subagents with 0 calls get no charts.
