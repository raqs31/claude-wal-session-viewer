### j. cleanPrompt (user reversed the 'raw prompt' decision, 2026-10-09)
Decision: ⚡ is baked into the server string (`prompt`, and so the `title` fallback), so the row, × chips, Sessions tab, agent picker and bubble all show the same text with no client code.
- `export const cleanPrompt = (raw: string): string | null` (pure). Steps:
  1. Drop blocks: `command-message`, `system-reminder`, any `local-command-*`. Innermost matching open/close pair first, repeated until nothing changes (handles nesting). An unclosed opener of these loses only its tag.
  2. Command: if a closed `<command-name>` block remains → result = `⚡ <name>` plus ` <args>` when `<command-args>` (cleaned the same way, whitespace kept as in step 4) is non-empty. Text outside these blocks is ignored in this case.
  3. Otherwise strip every remaining tag `</?[A-Za-z][\w:.-]*(\s[^>]*)?>`, keeping the text inside.
  4. Bubble text: newlines kept, 3+ newlines become 2, trimmed. Empty → null.
- prompt = cleaned ? cap(cleaned) : null (cap after cleaning). title fallback = prompt with whitespace runs collapsed to one space, trimmed.
