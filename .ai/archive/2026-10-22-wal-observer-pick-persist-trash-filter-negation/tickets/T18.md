Decisions:
- Restore needs no dialog; only the purge actions use typed yes, per the Intent.
- The summary is prefixed with the action ("Restore:", "Delete forever:", "Empty trash:") over the unchanged T15 summarizeResults. Conflicts are named as `title · short id (reason)`.
- Rows are keyed by source/date/slug/id, because the same id can be trashed twice. The selection clears after every action.
- Empty trash sends `{all:true}`, and the dialog lists the current entries.
- Usage tiles are hidden on Trash. The Trash tab renders without waiting for the session pick.
- The table sits in `.hscroll`, and the name column wraps (`overflow-wrap:anywhere`) rather than truncating, so narrow viewports still show it.
