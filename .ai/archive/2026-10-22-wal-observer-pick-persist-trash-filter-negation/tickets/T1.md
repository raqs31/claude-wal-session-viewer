## Context

Contract (plan.md Phase 1 §1, copied): "a validator for a stored pick (array of session-id strings, deduped); an `effective` function of `(wanted | null, sessions, gone, fallback)` returning the ids to show — `null` wanted → newest, `[]` → `[]`, non-empty that prunes to empty → the frozen fallback (newest at the moment it emptied). Existing `settlePick`/`prune` callers keep working or are replaced."

Rules to encode (plan.md Critical Implementation Details, pick persistence): two layers — the *wanted* pick (what storage holds and tabs share) and the *effective* pick (wanted minus ids this tab does not list or a stream reported unknown, recomputed whenever the list changes). When wanted is non-empty and effective is empty, the tab shows the newest session, frozen until wanted changes (no flicker as `last` moves). A toggle always starts from what is shown (the effective pick, or the fallback) and writes the result, so dead ids leave storage on the next user action and unpicking the last shown session gives `[]` (all sessions), not the fallback. Nothing stored (or an invalid value) behaves as today; a stored `[]` restores as all sessions.

Existing code: `newest` web/src/lib/pick.ts:4, `prune` :11, `settlePick` :18, `samePick` :24, `toggle` :26. Callers live in `web/src/usePick.ts:9` (T2 rewires them; keep exports T2 needs). Ids are valid when they match `SESSION_RE` (scripts/discovery.ts:11, `/^[0-9a-f-]{36}$/`) — copy the pattern rather than importing server code if web cannot import it.

Tests (plan.md Testing Strategy, one assertion each): stored-value validation (valid array, non-array, non-string member, duplicates deduped); `null` wanted → newest; `[]` → `[]`; partially pruned keeps the listed ids; pruned-to-empty → fallback; fallback frozen while `last` changes (sessions re-sorted, same fallback returned); unpicking the last shown session with a dead id in wanted → `[]`; adopting a pick with an id not yet listed keeps it in wanted so it shows once listed. Follow the existing style of web/src/lib/pick.test.ts.
