Decisions:
- Missing WAL: a target with head.wal true (in memory, or line 1 read by headOf) is skipped as in T3; only a session with no target or head.wal false is built from transcripts. Read-only mode skips a missing WAL as before.
- Replay: the parsers always re-read each transcript from byte 0. Keyed records diff against what absorb read from the whole target, so nothing is written twice. Rows from lines below ck.tr off are not written; rows after it are deduped by trRedo (transcript line uuid) and `called`.
- ck.tr holds only transcripts with off > 0, and a transcript's ino is kept only once bytes are read; so an empty transcript gives `tr: {}` (T3 assertion kept) and a replace before its first line is not stale.
- Stale reasons `transcript replaced` / `transcript shrank`. With no head yet, the session starts over instead (as the WAL rule).
- One Stop / SubagentStop per reply (message.id), at its first end_turn line: in 309 real transcripts, 204 of 603 end_turn replies span several end_turn lines, all with the same output_tokens. `out` = that line's usage.output_tokens.
- A main turn that a reply starts (slash command) takes the last `<command-` user line as `rec`; t = the parser's turnStart.
- No-WAL call rows: err = tool_result is_error === true; results are `tool_result` blocks in user lines and any `tool_use_id` block in assistant lines (server tools), as the parser reads them. The Agent tool gets a call row too.
- A row time with a missing timestamp falls back to the pass time (not persisted).
- Records are emitted only for transcripts that grew this pass (a new agent counts as grown); `tools` is written only when n differs from the last one (default 0), `cost` only when costUsd is not null. T6 must treat a missing `tools` as 0.
- Agent records come after all transcripts are read, because parent is looked up across all agents (sessions.ts:195).
- When the WAL vanishes between stat and open, the session's in-memory state is dropped (the pass's transcript records are not written); the next sync re-opens from the target.
